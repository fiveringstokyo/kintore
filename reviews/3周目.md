# 3周目

## 良くなった所
- 山本：「2セット目に 92.5 と入れたら3・4セット目も 92.5 になった。✓ を押して下の『保存して戻る』を押すだけ。**12タップで終わった**（1周目は18タップ＋記録更新の画面を閉じる手間）」
- 鈴木：「保存が一番下にずっとあるのがいい。前回と同じなら『種目を足す→ベンチ→次の種目へ→ショルダー→保存して戻る』で済む」
- 佐藤：「プランクが『30秒』で残った」

## 出た不満（ペルソナの声）

**鈴木（片手）**
- 「記録の無い日を開くと『右下の「＋ 種目を足す」から』と書いてある。その文字を押してしもうたけど何も起きん」
- 「『10月4日』だけやと、それが昨日なのか分からん。曜日も欲しい」

**佐藤（自重）**
- 「日の画面もホームも『総重量 0』『0 kg』。重さを使わん私には意味が無いし、やる気が下がる」
- 「新しい種目を作ったら部位が勝手に『胸』になっとった。プランクは胸やない」

**田中（初心者）**
- 「3日前のベンチを直しに行ったら『今日 37.5kg』と出る。3日前の画面なのに『今日』？」
- 「✓ の説明が3行あって読む気がせん」

**高橋（分析好き）**
- 「グラフを押しても何も起きん。ベンチを何日に何kg×何回やったか、一覧で見たい。どの日が一番よかったかも」

**山本（中級者）**
- 「種目の画面から、このベンチの今までの記録を見に行けたらいい（前回しか見えん）」

## 重い順に並べて直した事

| 重さ | 不満 | 直した事 |
|---|---|---|
| 重 | 種目ごとの日ごとの記録が見れん | **種目ごとの記録の一覧**を作った。ふり返りのグラフを押すか、種目の画面の「〇〇のこれまでの記録 ›」から開く。日付・曜日・やったセット・その日の推定MAX（自重は最高回数）、一番よかった日に 🏆。押すとその日を開く |
| 中 | 空の日の説明文を押してしまう | 記録の無い日は、真ん中に大きい「＋ 種目を足す」ボタンを出す |
| 中 | 自重の人に「総重量 0」 | 重さの無い日は「総重量」の代わりに「秒数」、ホームは「この7日のセット」を出す |
| 中 | 過去の日なのに「今日」 | 過去の日を直す時は「この日」と出す |
| 小 | 日付だけやと分からん | 「10月4日（日） 昨日」のように曜日と今日・昨日を出す |
| 小 | 部位が勝手に「胸」 | 新しい種目の部位は「その他」から始める |
| 小 | 説明が長い | ✓ の説明を1行に縮めた |
