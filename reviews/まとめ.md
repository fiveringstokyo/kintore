# まとめ：5周で何が変わったか

ペルソナ5人（[ペルソナ.md](ペルソナ.md)）に、iPhone 14 の画面サイズ・タッチ操作で5周使ってもらい、周ごとに不満を重い順に直した。
各周の中身は [1周目](1周目.md)／[2周目](2周目.md)／[3周目](3周目.md)／[4周目](4周目.md)／[5周目](5周目.md)、最後の画面は [5周目_スクショ/](5周目_スクショ/)。

## 数字で見る変化

| | 1周目（元の v1） | 5周目 |
|---|---|---|
| 44px 未満の押せる物 | 30か所以上（セットの −/＋ 34px、✓ 34px、× 19px、部位ボタン 25px…） | **0** |
| 自重で回数だけ入れて保存 | **記録が消えて画面が固まる** | 「自重 × 15回」で残る |
| 山本：ベンチ4セット（3セット重さを上げる）→保存 | 15タップ＋記録更新の画面を閉じる | **9タップ**（3周目に計測） |
| 鈴木：昨日の分を前回と同じ2種目で入れる | 11タップ（左上の戻るを2回） | **6タップ**（全部画面の下半分） |
| 高橋：ベンチの日ごとの数字を見る | できん | **3タップ**（ふり返り→グラフ→グラフを押す） |
| 画面に出る英語・専門用語 | Oct / MONTHLY ARCHIVE / TOTAL days / RM / 負荷量 / START | 無し（推定MAX には「1回だけ挙がる重さの目安」と説明を添える） |

## 利用者から見て変わった事

**記録をつける**
- 「今日の記録をつける」を押すと、すぐ種目の一覧が出る。
- 前回の重さ・回数が最初から入っとって、重さを1か所変えると下のまだ ✓ してないセットも同じに変わる。
- 種目の画面の一番下に「次の種目へ」「保存して戻る」が常にある（片手の親指で届く）。押せば必ず残る。
- 自重（重さ空っぽ）は「自重」、プランクなどは「秒」で残せる（新しい種目を作る時に数え方を選ぶ）。
- 種目の一覧に「チェストプレス」「腕立て伏せ」「ラットプルダウン」「レッグプレス」を足した。
- 自己ベストは画面を止めず、黄色い帯で「今日 92.5kg × 5回（これまでの一番：90kg × 5回・10/1）」と実際の重さで出る。自重は回数で比べる。
- 休憩タイマーは「1:30」の形。画面が消えても狂わん。

**見返す**
- カレンダーは日本語。やった日だけ白い丸。日付を開くと「10月4日（日） 昨日」。
- ふり返りのグラフは「週ごとの総重量」の棒（12週）と、種目ごとの伸び（「6/10 50kg → 10/3 73.8kg +23.8kg」）。
- グラフを押すか、種目の画面の「これまでの記録 ›」で、**種目ごとの日ごとの記録の一覧**（一番よかった日に 🏆）。
- 重さを使わん人には「総重量 0」を出さず、セット数や秒数を出す。

**記録を守る**
- 保存の形に版番号を足した（`ver: 2`）。古い記録はそのまま読め、移す前の中身を `kintore_v1_before_v2` に1回だけ控える。控えから読み込む時も、読み込む前の記録を `kintore_v1_before_import` に残す。
- 設定に「最後に控えを書き出した日」。記録が10日分以上あって控えが古い時は、ホームに小さく知らせる。
- `sw.js` のキャッシュを `kintore-v2` に上げ、古いキャッシュは消す。オフラインでも開けるのは今まで通り。

## まだ残る課題

1. **iPhone の実機で確かめとらん**。評価は Chromium で iPhone の画面サイズとタッチをまねた物。特に次は実機で確かめてほしい：休憩おわりの音（iPhone は振動が使えんので音だけ）、日付の入力、控えの書き出し（共有シート）、ホーム画面に置いた時の見た目。
2. **画面が消えとる間は休憩おわりを知らせられん**（Web アプリの決まり）。戻った時の残り時間は正しい。
3. **控えは手で書き出すしかない**。記録はスマホの中だけなので、スマホを失くすと控えより後の分は戻らん。
4. 種目の一覧は「最近やった部位が上」なので、片手やと上の方の種目に指が届きにくい（5周目でも1人あたり2回くらい画面の上1/3を押しとる）。
5. セットは「最後のセットを消す」しかできず、途中の1セットだけ消すことはできん（回数を 0 にすれば保存の時に消える）。
6. 同じ日に同じ種目を2回に分けて記録することはできん（1つにまとまる）。
7. 体重・体脂肪の画面はボタンの大きさを直しただけで、使い勝手は見直しとらん（5人の不満に出んかったため）。
